# seguridad-tecnologica-control-versiones
Repositorio para gestionar y realizar seguimiento de los cambios de código del sistema de Seguridad Tecnológica A Tu Alcance.

## Seguimiento de cambios

Este repositorio permitirá registrar las modificaciones realizadas por los equipos de desarrollo de Seguridad Tecnológica A Tu Alcance, facilitando el seguimiento de las actualizaciones e integración del trabajo realizado desde distintas ubicaciones.
